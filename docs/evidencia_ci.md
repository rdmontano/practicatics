# Evidencia de integración continua

El workflow está definido en `.github/workflows/ci.yml` y ejecuta restauración,
compilación y pruebas en cada push o pull request.

## Evidencia que debe incorporarse al documento madre

Después de publicar este repositorio en GitHub:

1. Abrir la pestaña **Actions**.
2. Ingresar a la ejecución **CI - Build y pruebas**.
3. Verificar que el job **Compilar y ejecutar pruebas** aparezca en verde.
4. Capturar la pantalla incluyendo el nombre del repositorio, el commit y el
   resultado de la etapa **Ejecutar pruebas automatizadas**.

No se incluye una imagen simulada: la evidencia académica debe provenir de una
ejecución real del repositorio.
